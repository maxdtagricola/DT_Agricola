Importação de Produtos

Ferramenta interna e temporária para cadastrar vários produtos de uma vez, usando os mesmos campos do cadastro individual.

Você precisa estar logado para usar esta ferramenta.

Ir para o Login

Como funciona: a planilha deve ter, na primeira linha, os nomes das colunas — nome, marca, referencia, categoria, medidas, valor, quantidade, imagem, descricao — a ordem das colunas não importa.

Se o produto (pela referência) já existir no catálogo, só a disponibilidade é atualizada, calculada a partir da quantidade: maior que zero vira "Em estoque"; zero ou negativo vira "Indisponível". Os demais dados do produto existente não são alterados.

Se a referência ainda não existir, um produto novo é cadastrado com os dados da planilha.
